# Описание проекта:
Разработка реляционной базы данных для интернет-магазина (маркетплейс)

# Сущности:
1. Users (Пользователи)
2. Sellers (Продавцы)
3. Products (Товары)
4. Offers (Предложения продавцов)
5. Categories (Категории)
6. Cart_items (Содержимое корзины)
7. Orders (Заказы)
8. Order_items (Состав заказа)
9. Payments (Оплата)
10. Deliveries (Доставка)
11. Pickup_points (Пункт выдачи)
12. Reviews (Отзывы)
