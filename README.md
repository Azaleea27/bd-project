# Описание проекта:
Разработка реляционной базы данных для интернет-магазина (маркетплейс)

# Сущности:
1. Users (Пользователи)
2. Sellers (Продавцы)
3. Products (Товары)
4. Categories (Категории)
5. Cart (Корзина)
6. Cart_items (Содержимое корзины)
7. Orders (Заказы)
8. Orders_items (Состав заказа)
9. Pyments (Оплата)
10. Deliveries (Доставка)
11. Pickup_points(Пункт выдачи)
12. Reviews (Отзывы)
